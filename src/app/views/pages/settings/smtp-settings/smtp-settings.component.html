SMTP Configuration Help

Gmail

  • Host: smtp.gmail.com
  • Port: 587 (TLS) or 465 (SSL)
  • Username: your full Gmail address
Important: Use an App Password (Google Account → Security → 2-Step Verification → App passwords).

Outlook / Hotmail

  • Host: smtp.office365.com
  • Port: 587
  • Encryption: TLS
Note: Use your Microsoft account email and password (or app password if enabled).

Yahoo

  • Host: smtp.mail.yahoo.com
  • Port: 465 or 587
  • Encryption: SSL / TLS
